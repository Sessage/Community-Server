# Änderungen beitragen

`Sessage/Community-Server` ist ein automatisch erzeugter Veröffentlichungsspiegel. Bitte keine dauerhaften Änderungen ausschließlich in diesem Repository vornehmen: Der nächste Abgleich bildet wieder den freigegebenen Stand des zentralen Monorepos ab.

Für Fehlerberichte und Änderungsvorschläge kann die Issue-Funktion dieses Repositorys verwendet werden. Die eigentliche Quellcodeänderung wird im zentralen Entwicklungsrepository vorgenommen und anschließend automatisiert veröffentlicht.
