# Sicherheit

Sicherheitsrelevante Funde sollten nicht zusammen mit ausnutzbaren Details als öffentliches Issue veröffentlicht werden. Melden Sie diese über den von der Sessage-Organisation angegebenen privaten Sicherheitskontakt oder die GitHub-Funktion **Report a vulnerability**, sobald sie für dieses Repository aktiviert ist.

Die Konfigurationswerte im Quellcode sind nicht für öffentlich erreichbare oder produktive Systeme bestimmt. Verwenden Sie für Datenbank-, SMTP-, JWT- und Verzeichnis-Zugangsdaten geschützte Umgebungsvariablen oder einen Secret Store und committen Sie niemals echte Zugangsdaten.
