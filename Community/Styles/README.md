# Tailwind build compatibility

Tailwind 4 and `@tailwindcss/cli` replace Tailwind 3's vulnerable braces/selector
parser dependency chain. The CLI currently pins Parcel Watcher 2.5.1; the npm
override selects 2.6.0, which replaces micromatch/braces with picomatch.

`tailwind.compat-theme.json`, `tailwind.compat-preflight.css` and
`tailwind.compat-utilities.css` preserve the previous palette, utility scales,
base styles and existing utility declarations. They contain static
theme/CSS data, not the vulnerable Tailwind 3 build dependencies. Their upstream
MIT license is included in `tailwind.compat-LICENSE.txt`.

`Scripts/build-tailwind.cjs` flattens generated CSS layers so that existing shared
styles keep the previous cascade, including in MAUI WebViews supporting iOS 15.
The v3 palette also avoids introducing color-mix dependencies in color utilities.
Already-used utility selectors use their compiled v3 declarations; new utility
classes are generated by v4. This retains transform and sibling-spacing behavior
without rewriting the Razor UI or increasing the existing WebView requirements.
To intentionally migrate an existing utility's design, remove its compatibility
rule and verify the corresponding view. No old npm compiler is required.
Build with `npm run tw:build`, watch with `npm run tw:watch`. Both invoke the same
Tailwind 4 compiler and publish the compatibility-processed CSS file.
